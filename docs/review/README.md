# Demo27 — пакет учебного ревью

Документы подготовлены по содержимому ZIP-архива проекта.

1. `repo_map.md` — карта репозитория.
2. `checklist.md` — чек-лист ревью.
3. `style_report.md` и `style_report.txt` — анализ стиля.
4. `logic_report.md` — API, логика и данные.
5. `security_report.md` — подтверждённые и требующие динамической проверки security findings.
6. `deps_report.md` — анализ списка зависимостей.
7. `review_report.md` — итог, приоритеты и план исправлений.

Ограничения: синтаксическая компиляция Python выполнена. pytest не смог стартовать из-за отсутствующего Flask в runtime. flake8/pylint не установлены. XSS-поведение не проверялось в браузере; отчёт отмечает статически выявленные опасные DOM sinks. Исправления исходного приложения не внесены.
