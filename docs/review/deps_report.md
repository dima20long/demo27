# Отчёт по зависимостям

## Список
`requirements.txt` содержит:
- Flask >= 3.0.0
- Flask-SQLAlchemy >= 3.1.0
- Flask-Login >= 0.6.0
- Flask-Migrate >= 4.0.0
- Werkzeug >= 3.0.0
- Pillow >= 10.0.0
- psycopg2-binary >= 2.9.0
- python-dotenv >= 1.0.0
- alembic >= 1.13.0

## Замечания
- Используются открытые нижние границы версий без верхних ограничений/lock-файла; повторяемость установки и контроль обновлений ограничены.
- `psycopg2-binary` удобно для учебной разработки, но для deployment следует отдельно оценить предпочтительный драйвер/способ сборки.
- Отчёт CVE/актуальности версий не проводился: текущая среда не имеет доступа к онлайн базе уязвимостей. Нельзя утверждать, что зависимости уязвимы или безопасны без проверки версий и CVE.
- Рекомендации: создать lock-файл; регулярно обновлять зависимости; проверять CVE (pip-audit/Dependabot); фиксировать результаты и дату анализа.
