# Boss Review Project (Demo27)

Проект для демонстрации навыков код-ревью.

## Структура
- `app/` — исходный код (Flask)
- `docs/review/` — отчёты по дням (стиль, логика, безопасность)
- `database/` — SQL-схемы
- `web/` — HTML-шаблоны

## Запуск
1. Создайте виртуальное окружение: `python -m venv .venv`
2. Активируйте его: `.venv\Scripts\activate`
3. Установите зависимости: `pip install -r requirements.txt`
4. Запустите: `python run.py`
