# Карта репозитория Demo27

## 1. Назначение проекта

Demo27 — Flask-приложение для управления производственными данными. В проекте предусмотрены функции работы с клиентами, продукцией, материалами, операциями, спецификациями, заказами покупателей и производственными заказами.

## 2. Запуск и конфигурация

- `run.py` — точка входа в приложение.
- `app/__init__.py` — создание приложения, подключение расширений, регистрация маршрутов и настройка обработчиков.
- `app/config.py` — конфигурация приложения и параметры подключения к БД.
- `app/extensions.py` — расширения Flask, SQLAlchemy и Flask-Login.
- `requirements.txt` — список зависимостей Python.

## 3. Структура приложения

- `app/models.py` — модели данных и ORM.
- `app/dtos/` — объекты передачи данных (DTO).
- `app/repositories/` — слой доступа к данным.
- `app/services/` — слой бизнес-логики.
- `app/views/` — представления и обработчики API.
- `app/blueprints/` — модули маршрутов, организованные по функциональным областям.
- `app/auth.py` — функции хеширования и проверки паролей.
- `app/utils.py` — вспомогательные функции.
- `app/puzzle_captcha.py` — логика CAPTCHA.
- `app/blueprints/puzzle_captcha.py` — модуль CAPTCHA в составе Blueprint.
- `app/blueprints/web.py` — обработчики веб-страниц.
- `web/` — HTML, CSS и клиентская часть приложения.
- `tests/` — автоматические тесты.
- `database/` — SQL-файлы схемы и вспомогательных запросов.
- `image/` — изображения, используемые приложением.

## 4. Предполагаемый поток обработки запроса

1. `run.py` запускает приложение.
2. Flask создаёт приложение через фабрику `create_app()`.
3. Регистрируются расширения и маршруты.
4. Обработчик принимает запрос.
5. При наличии соответствующей архитектуры обработчик обращается к сервису.
6. Сервис выполняет бизнес-логику и взаимодействует с данными.
7. Репозиторий и ORM выполняют операции с базой данных.
8. DTO формирует данные ответа.
9. Клиент получает JSON-ответ или HTML-страницу.

Фактическое использование всех слоёв требует проверки исходного кода.

## 5. Основные функциональные области

- Авторизация и регистрация пользователей.
- Администрирование.
- Клиенты.
- Продукция.
- Материалы.
- Операции.
- Спецификации.
- Заказы покупателей.
- Производственные заказы.
- Заметки.

- Обработка ошибок и исключений.
- Корректность ORM-запросов.
- Транзакции и целостность данных.
- Работа с ценами, заказами и производственными данными.
- Проверка безопасности HTML и JavaScript.

- Проверка дублирования маршрутов и бизнес-логики.
